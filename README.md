# Сайт ArtoFIX 2.5

Статический сайт для GitHub Pages. Оформление и структура сохранены из этого репозитория. Это описание приложения, не перенос Electron/Python-движка в браузер. Сборка сайта не нужна.

## Принцип текстов

Спокойный, доброжелательный тон: описываем возможности, кратко сообщаем, что приложение развивается и отдельные функции дорабатываются. Вместо отдельного раздела предупреждений — блок обратной связи после возможностей с прямой ссылкой на GitHub Issues. Экран скачивания содержит короткую информацию о доработке и настройке.

Не обещаем универсального обхода, анонимности или отсутствия ошибок. Существенные уточнения остаются в FAQ: выбор страны не меняет IP, команды WARP относятся к диагностике/DNS, а не созданию туннеля. SHA-256 и инструкция проверки сохранены без заявления, что хеш подтверждает безопасность архива.

Основание: код [Artins200/ArtoFIX-2.5](https://github.com/Artins200/ArtoFIX-2.5/tree/5e32f0842a370fe6c896f8ee9119c1df08e99f26). В `main.js` функции `cbnTestWarp` / `cbnFixWarp` проверяют TCP-доступность адресов и пытаются менять DNS/DoH через PowerShell, но не проверяют работу WARP-туннеля. Проверка обновлений `zapretCheckUpdate` относится к Zapret, а не подтверждает автообновление всей оболочки. Утверждения из описания релиза не считаются доказательством исправления всех ошибок или результатом аудита.

## Закреплённый файл

- Релиз: [2.5.2](https://github.com/Artins200/ArtoFIX-2.5/releases/tag/2.5.2).
- Файл: [ArtoFix.2.5.rar](https://github.com/Artins200/ArtoFIX-2.5/releases/download/2.5.2/ArtoFix.2.5.rar).
- Размер из GitHub API: 86 462 032 байта.
- SHA-256 от автора, совпадающий с `digest` в GitHub API:

```text
5e3f4c3c7fd58b1c72bdf42ad1e94a030433ccc9dade10d70d893572c0161248
```

Обе кнопки ведут на этот конкретный архив, в том числе без JavaScript. Автоматический выбор последнего релиза удалён: нельзя менять файл, сохраняя хеш предыдущего. При обновлении вручную замените обе ссылки, подписи, размер, хеш и соответствующие тесты.

Контрольная сумма сверена **с метаданными GitHub**, а не вычислена нами из архива: загрузка архива в рабочей среде завершилась сетевой ошибкой. Антивирусная проверка, запуск Windows-приложения и проверка соответствия архива исходникам не проводились. Хеш не заменяет их. На сайте есть команда PowerShell для самостоятельной проверки скачанного файла.

## Просмотр и тесты

```sh
python3 -m http.server 8080 --bind 0.0.0.0
node --test tests/*.test.js
```

Для тестов нужен Node.js 18+, сторонних зависимостей нет. Тесты проверяют ссылки, хеш, якоря, отсутствие прежних обещаний и синтаксис JavaScript — это проверки **сайта**, не эффективности приложения.

Ручная проверка: обе кнопки → информация о доработке → ссылка на архив; закрытие крестиком/Escape и возврат фокуса; FAQ; инструкция SHA-256; мобильные экраны 320–390 px; доступность ссылок и текста с выключенным JavaScript.
